# Online Shopping Cart

A clean and attractive E-Commerce shopping cart built with React. This project demonstrates advanced state management using the **Context API** and the **`useReducer`** hook.

## Features

- **Product Listing:** Browse a realistic collection of products with high-quality images.
- **Cart Management:** Add products, update item quantities, and remove items dynamically.
- **Global State Management:** Completely centralized cart state using React's `useReducer` to avoid prop-drilling.
- **Promotional Coupons:** Apply discount codes (e.g., `SAVE10`, `SAVE20`) to dynamically reduce the subtotal by a percentage.
- **Financial Breakdown:** Automatically calculates the Subtotal, Coupon Discounts, GST (18%), and Grand Total in real-time.

## Technologies Used

- React (Context API & useReducer)
- CSS3 (Flexbox & CSS Grid)

## How to Run

1. Open your terminal and navigate to the project directory:
   ```bash
   cd 5.online-shopping-cart
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.
